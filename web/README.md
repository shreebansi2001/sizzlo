# Sizzlo Web Admin (React 18 + TypeScript + Vite)

Executive operations and management portal for the Sizzlo platform and Yanki Hospitality Group.

## Key Modules
- **Executive Overview (Dashboard)**: Real-time KPIs, revenue & membership trends, venue performance comparison, and live reservation floor pipeline.
- **CEO Strategic Suite**: Group margins, customer retention rate (88.6%), and forward-quarter growth forecasting.
- **Customer 360 CRM**: Comprehensive member records, spending history, coupon utilization, loyalty points, and pending dues tracker.
- **Voucher Manager**: Create, configure, publish, and track dining privilege vouchers and anniversary specials.
- **Host Station & Table Reservations**: Table booking status management (seat guests, confirm, cancel) with VIP notes.
- **Venues & Dining Concepts**: Outlets directory, revenue per outlet, average bill value (ABV), and customer ratings.
- **AI Predictive Engine**: Automated intelligence suggesting renewal campaigns, capacity surges, and revenue boosters.

## Running Locally
```bash
npm install
npm run dev
```
Runs at `http://localhost:5173`. Proxies `/api` requests to Spring Boot backend at `http://localhost:8080`.
